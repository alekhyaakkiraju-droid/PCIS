# Intent profile

**Status:** complete

**Artifact:** `526ec2f8-0bc7-4bdd-83f7-1ac226ea647e`

## Vision

Modernize PCIS (Property & Casualty Insurance System) from an IBM i / ILE COBOL green-screen application into a modular, API-driven Java platform — replacing 5250 DDS panels with an accessible web UI, converting COBOL batch programs into Spring Batch services, migrating embedded SQL and DB2 for i schemas to a cloud-ready PostgreSQL model, and exposing Claims, Customer, Policy, Premium, Billing and Reporting workflows as versioned REST microservices — while preserving 100% of evidenced business behaviour and closing the audit, authorization and PII control gaps identified in the assessment.

- **Domain microservices for Claims, Customer, Policy, Premium, Billing and Reporting** (priority 1)
- **Shared kernel: authorization (SECCHK01) and audit logging (AUDLOG01) as first-class services** (priority 2)
- **COBOL batch to Spring Batch conversion with preserved commit semantics** (priority 3)

## Technical constraints

- Source platform: IBM i (AS/400), IBM ILE COBOL (Enterprise COBOL for i) fixed-format, embedded static SQL against DB2 for i, DDS physical/logical files and 5250 display files
- Target platform: modular, API-driven Java architecture (Spring / Spring Batch) with RESTful microservices and a cloud-ready relational database (PostgreSQL)
- Embedded static SQL is precompiled and bound as packages; PostgreSQL has no static-bind equivalent, so every EXEC SQL statement must be re-hosted via JDBC/ORM/DAO — application refactoring, not schema conversion, is the dominant effort
- All core business capabilities across Claims, Customer, Policy, Premium, Billing and Reporting must be preserved (functional parity)
- Exact decimal precision must be preserved: COMP-3 S9(9)V99 / S9(11)V99 → DECIMAL(9,2) / DECIMAL(11,2) and BigDecimal in Java
- Business document keys must remain SEQUENCE-generated fixed-length VARCHAR/CHAR values, not IDENTITY columns
- Deny-by-default access control is an organization policy requirement on all financial mutations
- Organization policy requires PII masking in logs, per-entity data classification, and automated purge with a defined retention period
- Organization policy forbids silently swallowing errors and requires structured logging with actor/resource/operation context
- User interfaces must meet WCAG 2.1 AA (keyboard, screen reader, contrast) — unattainable with 5250 green-screen panels
- Segregation of duties between claim approval (CLM003A) and claim payment (CLM006B) is a mandatory architectural control
- IBM Enterprise COBOL currency: 6.5.x is current (GA 2025-06-13), 6.4 supported with continuous-delivery PTFs and Java 17/21 interop; 6.3.x reached end of support 2025-09-30 with extended support to 2028-09-30; 4.2/5.1/5.2 are EOS. The target compiler release must be recorded and on a supported level during coexistence
- Library/environment topology must be respected during transition: INSDEV/INSDEVDTA, INSTST/INSTSTDTA, INSPRD/INSPRDDTA, INSCOM (shared service programs and copybooks), INSTOOLS (build and scheduler objects); INSPRDDTA is the only library holding real customer data
- No test harness, CI/CD, container, IaC or API surface exists today — this plumbing is a prerequisite for all other work
- Repository is incomplete: CLM006B.cbl and CMM001B.cbl are empty, CUS_Module_Design_Document.md is empty, and CLM001A–CLM005A are design-only specifications
- Cutover must minimize downtime via phased migration with parallel-run comparison; polling-based extraction may be more practical than CDC on IBM i
