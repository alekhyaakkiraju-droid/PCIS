# PCIS Glossary

| Term             | Definition                                                    |
|------------------|---------------------------------------------------------------|
| FNOL             | First Notice of Loss — first report of an insurance claim     |
| Reserve          | Amount set aside to cover expected claim payment              |
| Adjuster         | Insurance professional who evaluates and processes claims     |
| Authority Limit  | Maximum dollar amount an adjuster can approve without review  |
| Installment      | Periodic payment toward annual premium                        |
| DDS              | Data Description Specifications — IBM i display file format   |
| CL               | Control Language — IBM i scripting language                   |
| ILE COBOL        | Integrated Language Environment COBOL on IBM i                |
| Missing-Callee   | Program referenced by CALL but absent from repository         |
| Design-Only      | Program specified in design docs but no source member exists  |
