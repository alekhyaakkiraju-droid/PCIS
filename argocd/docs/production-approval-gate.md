# Production approval gate for Argo CD (WO-139)

Argo CD applications targeting **production** (`pcis-prd` namespace) require explicit human approval before sync. Non-production environments follow the sync modes below.

## Sync modes by environment

| Environment | Namespace   | Sync mode   | selfHeal | prune | revisionHistoryLimit |
|-------------|-------------|-------------|----------|-------|----------------------|
| dev         | `pcis-dev`  | Automated   | yes      | yes   | 5                    |
| tst         | `pcis-tst`  | Manual      | no       | no    | 5                    |
| prd         | `pcis-prd`  | Manual gate | no       | no    | 5                    |

Automated sync is enabled only for **dev** applications generated by `argocd/applicationsets/pcis-services.yaml` and `argocd/applicationsets/pcis-batch.yaml`.

## Production approval annotations

Applications with `pcis.environment=prd` carry these metadata annotations (set by ApplicationSet templates):

| Annotation | Purpose |
|------------|---------|
| `pcis.governance/approval-required: "true"` | Marks the Application as change-controlled |
| `pcis.governance/approver-group: pcis-admins` | IAM / IdP group allowed to click **Sync** in Argo CD UI or CLI |
| `pcis.governance/change-ticket-required: "true"` | Operator must attach a change ticket before sync |
| `notifications.argoproj.io/subscribe.on-sync-*` | Slack alerts to `#pcis-prod-deployments` / `#pcis-prod-alerts` |

The `pcis` AppProject (`argocd/projects/pcis-project.yaml`) enforces:

- `syncWindows` deny window on `pcis-*-prd` with `manualSync: true` (only explicit manual sync allowed)
- RBAC role `prod-approver` bound to `pcis-admins` for production sync actions

## Approval workflow

1. CI merges a signed image digest bump to `main` (Helm value or Kustomize overlay).
2. Argo CD detects OutOfSync for the prd Application but does **not** auto-sync.
3. On-call verifies the change ticket, migration notes, and rollback digest (see `ops/runbooks/rollback.md`).
4. A member of `pcis-admins` runs:

   ```bash
   argocd app sync pcis-<service>-prd --revision <git-sha> \
     --annotation pcis.governance/change-ticket=<TICKET-ID>
   ```

5. Notifications fire on sync running / succeeded / failed per `argocd/notifications/config.yaml`.

## tst manual sync

Test (`tst`) applications are also manual sync to mirror production behaviour without the full change-control gate. Deployers in `pcis-deployers` may sync tst applications after integration sign-off.
